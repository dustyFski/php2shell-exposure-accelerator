What should we check?

Only check systems you own or are authorised to assess. Checks read HTTP response headers and Azure metadata only; no exploit traffic is ever sent.

How it works

1 · URL Scanner agent checks the PHP version each site advertises against the PHP2Shell vulnerable-version table (same logic as OpenAI's open-source php2shell-checker).

2 · Azure Inventory agent uses Azure Resource Graph to find PHP workloads and shows who patches them: the platform or you.

3 · Remediation Advisor agent turns the findings into a prioritised plan: patch versions, php.net interim mitigations, Azure WAF and detection.

Orchestrator agent combines all three for a conversational assessment.

The AI features send scan targets and findings to the Azure AI Foundry agents and the model deployment configured for this portal, which may process them in other Azure regions depending on the deployment type (for example GlobalStandard). Not an official Microsoft or PHP advisory. This is a version-based exposure check, not proof of compromise or of patching: headers can be hidden or changed, and vendor backports may fix older version numbers. "Unknown" does not mean patched. Upgrading PHP is the only complete fix.
